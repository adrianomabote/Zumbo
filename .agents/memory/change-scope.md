---
name: Escopo das alterações
description: Limitar cada pedido às alterações explicitamente solicitadas pelo utilizador.
---

Cada alteração deve fazer apenas o que o utilizador mandar, para evitar gastar tempo e tokens desnecessários.

**Why:** O utilizador pediu explicitamente esta restrição ao importar o projecto.

**How to apply:** Não configurar execução, refactorizar, alterar outros ecrãs ou ampliar funcionalidades quando o pedido for uma edição específica.
