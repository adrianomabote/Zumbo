---
name: Perfil do utilizador
description: Preferência visual confirmada para a área de perfil
---

“Meu Perfil” deve abrir como uma vista de ecrã inteiro, não como um diálogo central. A área de perfil não deve exibir indicações de prefixos ou métodos de pagamento.

**Why:** O perfil é uma área de gestão própria e precisa de mais espaço; as regras de prefixos pertencem ao número de pagamento no checkout.

**How to apply:** Preservar a apresentação full-screen e manter o perfil focado em dados pessoais e alteração de senha.
